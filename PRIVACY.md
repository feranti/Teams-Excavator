# Privacy Policy

_Last updated: 2026-10-17_

This policy applies to the browser extension **Teams Excavator** (the "extension").

## Summary

The extension runs entirely in your browser. It does not collect, transmit, sell or share any personal data. There is no server, no account, no analytics and no tracking.

## Data the extension accesses

When you start an extraction, the extension reads the content of the Microsoft Teams chat or channel you have open: message text, authors, timestamps, reactions, attachments and inline images. It also fetches the attachments and images you choose to export from Microsoft-hosted domains (Teams, SharePoint, OneDrive).

This data is processed locally, in your browser, only to build the export file you requested (CSV, HTML, Markdown or ZIP). The resulting file is saved to your computer through the browser's download manager.

## Data the extension stores

The extension stores only your own preferences (such as interface language and export options) in the browser's local extension storage. This data never leaves your device.

## Data sharing

None. The extension does not send data to the developer or to any third party. It makes no network requests other than to Microsoft domains, to read the content you export.

## Remote code

The extension does not load or execute remote code. All code is bundled in the extension package.

## Permissions

- **activeTab, scripting**: run the extraction in the Teams tab you are using.
- **storage**: save your preferences locally.
- **downloads**: save the exported files.
- **Host permissions** (Teams, SharePoint, OneDrive and Teams media domains): read the conversation and download the attachments and images you export.

## Your responsibility

Exported files contain your Teams conversations and may include sensitive or confidential information. Store and share them in accordance with your organization's policies.
