# Changelog

All notable changes to this project are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/).

## [0.9.1] - 2026-10-17

### Added

- Privacy policy (`PRIVACY.md`).
- 96×96 icon.
- Chrome Web Store visuals: screenshots, small promo tile and marquee.

### Changed

- Refreshed extension icons; the 16×16 icon is dropped in favor of the 96×96 one.
- The popup's support button now reads "Buy me a beer" in all 20 locales.

## [0.9.0] - 2026-10-01

### Added

- Initial release: chat and channel extraction from Teams on the web, with CSV, HTML, Markdown and attachment ZIP exports, batch mode and 20 locales.
